# Inside the Exchange
Educational interactive stock exchange matching engine simulator.


## Local setup
1. Install Node.js 18+.
2. In this folder run `npm install`.
3. Run `npm run dev` and open the localhost URL shown.

## Current MVP
- Demo order book
- Market and limit orders, buy and sell
- Price-time priority
- Partial fills
- Last trade price updates on execution
- Cancel resting orders

This is educational only. It is not connected to any real exchange, broker, or market data.
